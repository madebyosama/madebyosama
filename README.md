<summary><b>Common questions — answered</b></summary>

<br />

**How do I get started?**
Schedule an intro call, fill out the form on my site, shoot me an email, or slide into my DMs. Whatever feels right. I'm easy to reach and always up for a chat.

**Which package should I choose?**
After a sleek one-pager? The Landing Page package. Need more depth? The Multi-Page option. Something custom? Let's talk it through — flexibility is part of the process.

**What if I need custom code in WordPress?**
No problem. From plugins to custom fields, I can tailor the backend exactly how you need it.

**How many revisions do I get?**
I don't count revisions. We refine until it's right — within reason. It's about building something we're both proud of.

**I already have a design. Can you develop it?**
Absolutely. If the design is clean and organized, I'll bring it to life in WordPress, Framer, or wherever you need it.

**I already have a website. Can you redesign it?**
Redesigns are my favourite. There's something satisfying about leveling up an existing brand with a fresh feel.

**What if I'm not happy with the results?**
I'll keep iterating with you until it's right. I don't offer refunds, but I do offer dedication.

**Can you help me with branding?**
Yes. I started out in branding before web stole my heart. Logos, voice, and identity design are all in my zone.
